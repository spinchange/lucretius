# Fidelity Review Rubric (Lucretius)

The reviewer's rubric is embedded in `prompts/fidelity.md`; this file records
the categories and severities for the human reader and for the findings
files. Categories: MISTRANSLATION, OMISSION, ADDITION, GRAMMAR, AMBIGUITY,
LEXICAL, REGISTER, LINEATION. Severities: CRITICAL, MAJOR, MODERATE, MINOR.
Firm findings need confidence >= 0.75; 0.50-0.74 are listed as SECONDARY.
Register choices listed in `translation/CONVENTIONS.md` are not findings.
