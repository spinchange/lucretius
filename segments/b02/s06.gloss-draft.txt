FINDINGS
865	AMBIGUITY	MAJOR	0.70	"ea quae sentire videmus cumque" (whatever things we see to be sentient) is rendered "all the things we see have sense", which a reader takes as a main clause asserting that everything visible is sentient, the reverse of the argument (sentence 865-867); "Now all the things that we see to have sense, whatever they are,"
861	LEXICAL	MINOR	0.65	"a principiis" is rendered "first-beginnings", and the note claims identical rendering is the policy; the register fixes principia = "beginnings" to keep it distinct from primordia, and the same slip recurs at 867 "insensilibus principiis", 947 "positurae principiorum" and 969 "principiorum corporibus"; "all these must be kept apart from the beginnings," (likewise 867 "senseless beginnings", 947 "the positions of the beginnings", 969 "any beginnings'"), and drop the note.
864	LEXICAL	MINOR	0.50	"ne tibi res redeant ad nihilum funditus omnes" is a fixed refrain (2.864 = 2.756 = 1.673 = 1.797), but the English recasts it as "or else all things will return for you utterly to nothing" instead of the verbatim register line; "so that all things do not return utterly to nothing for you."
